# OFFICE-DESIGN — дизайн офиса (back-office) Sandyq

> Статус: спецификация от 2026-09-24; по ней построен офис (W0–W3): все разделы, кроме «План счетов» (заглушка «Раздел в разработке»), работают, «Касса» — ссылка на `/pos`, «Экран кухни» — раздел офиса. Общие правила дизайна приложения теперь сведены в корневом `DESIGN.md`; значения токенов — `frontend/app/shared/styles/theme.css`.
> Токены, шрифты, примитивы и общие правила — в `04-POS-DESIGN.md` §1–5 и §10. Этот документ их не повторяет, а описывает только офис.
> Что переносим и в каком порядке — `reference/archive/PLAN.md` (§4.3 разделы офиса, §12 баги стенда, §13 матрица паритета).
> Скриншоты bahandi удалены 2026-09-27; имена файлов ниже — исторические ссылки на стенд bahandi.

**Правило (решение пользователя):** раскладка и состав каждого экрана — как в bahandi, визуальный стиль — Sandyq. Переносим все 90 разделов и 12 групп меню в том же порядке.

## 3. Шаблоны страниц

### 3.1 Реестр (Register)
Образцы: `office/03-orders.jpg`, `10-nomenclature.jpg`, `14-price-orders.jpg`, `18-receipts.jpg`.

```
PageHeader
```

- **Табы** — как у bahandi, с подчёркиванием `--accent`. Счётчик 12 px muted.
- **Таблица**: заголовки 12 px 600 sentence case, строки 48 px 14 px.
  - Числа справа, tabular-nums; суммы — Golos 500 с `₸` (Cormorant только в KPI и итогах).
  - Номер документа моноширинный не нужен, Golos 600.
  - Hover строки — `--muted`. Клик по строке открывает детали. Стрелка «›» справа, как у bahandi.
  - Выбранная строка: полоска 2 px `--gold` слева.
- **Детали:**
  - для заказов и смен — правая панель 440 px (≥1440) или выдвижная (<1440). Сейчас в bahandi на 1341 px панель не открывается (L-17);
  - для документов — отдельная страница-редактор (§3.4) с маршрутом `/office/<section>/<id>`.
- **Пагинация** «Показать ещё» + «Загружено N из M». В bahandi M не показан.
- **Пустое состояние** — EmptyState: орнамент + «Записей пока нет» + primary из шапки.
- **Загрузка** — Skeleton 6 строк, а не текст «Загружаем…».

### 3.2 Справочник с публикацией (Settings)
Образцы: `office/05-payment-types.jpg`, `06`, `07`, `08`.

- **Как у bahandi:**
  - список записей (название, код · версия · дата начала, статус);

  - кнопки «Сохранить черновик / Опубликовать».
- **В Sandyq:**
  - **master-detail** (≥1280): список 360 px слева, форма справа. Ниже 1280 — форма в выдвижной панели;
  - «Рестораны» — Combobox с чипами вместо нативного `multiple` (`office/05`: серый нативный список);
  - статусы на русском: «Черновик / Опубликовано / Истекло» вместо PUBLISHED (L-9);
  - флаги поведения — Switch в две колонки с подписью и пояснением.

### 3.3 Мастер-данные (Master)
Образцы: `office/11-product-groups.jpg`, `15`, `16`, `24`, `25`, `60`, `61`, `64`.

- **Как у bahandi**: карточки-строки (название + вторая строка мета), форма «Новая запись», чекбоксы «Активна» и т. п.
- **В Sandyq**: тот же master-detail, что в §3.2. Строка списка — название 14 px 600, мета 12 px muted, справа StatusPill.
- **Особые формы:**
  - зоны доставки — карта справа от списка вместо поля «одна координата на строку»;
  - курьеры — строка с кнопками «Закрыть смену / Изменить» остаётся, как у bahandi (`office/61`).

- **Техкарта** (`office-details/01`): KPI «Цена продажи / Себестоимость порции / Фудкост / Выход одной порции», таблица «брутто / нетто / потери», «Выпуск и списание», «Проверка техкарты». Фудкост раскрашивается по порогам: success < 30 %, warning 30–35 %, destructive > 35 %.
- **Приказ о ценах** (`office-details/10`): таблица «Вкл / Наименование / Размер / Было / Новая цена / Наценка / 🗑». Наценка считается от себестоимости техкарты; в bahandi у всех строк 140 % (L-19).

### 3.5 Реестр доменных записей (Domain)
Образцы: `office/27…58`, `65…77`, `83…90`.

- **Как у bahandi**:
  - табы жизненного цикла;
  - опциональная панель над поиском (прогноз кухни, импорт CSV, расчёт ведомости, счётчик истекающих документов);
  - поиск + «N записей»;
  - таблица.
- **В Sandyq:**
  - **Табы по жизненному циклу модуля** (в bahandi везде одинаковые 5 табов):
    - master: «Все / Активные / Неактивные»;
    - publish: «Все / Черновики / Опубликованные / Неактивные»;
    - approval: «Все / Черновики / На согласовании / Согласованные / Проведённые»;
    - document: «Все / Черновики / Проведённые / Сторно».
  - **Колонки из конфига модуля** (§5), а не общая «Сумма / значение» (L-10: «1 ₸» у сотрудника, «8 ₸» у часов смены).
  - **KPI только свои** (L-11): одинаковый блок финансовых KPI не копируется на все страницы.
  - Карточка записи — Editor §3.4 с блоками «Основные реквизиты / Параметры / Строки / Проведение и аудит».

### 3.7 Дашборд
Образец: `office/01-dashboard.jpg`.

- **Как у bahandi**: 4 KPI в ряд (Выручка, Оплачено заказов + средний чек, Проведено документов + черновики, Ошибки обмена), «Рестораны сети» (название, документы, оборот, статус), «Быстрый доступ».

  - «Избранное» — отдельная страница закреплённых разделов и отчётов (в bahandi это копия дашборда, L-8).

## 7. Состояния и поведение

| Состояние | Спецификация |
|---|---|
| Загрузка страницы | Skeleton шапки таблицы + 6 строк. Не текст «Загружаем рабочий модуль…» |
| Пусто | EmptyState: орнамент 96 px `--gold`, заголовок Cormorant 22 px, одна строка, primary-действие. Тексты — как у bahandi («Записей пока нет. Создайте первую рабочую запись.») |
| Ошибка запроса | Баннер `--destructive` над таблицей с текстом ошибки из `ConvexError` и кнопкой «Повторить» |
| Несохранённые изменения | Индикатор в крошках «● Есть несохранённые изменения» (`--warning`), как у bahandi. Подтверждение при уходе со страницы |
| Сохранено | «● Все изменения сохранены» (`--success`) |
| Уведомления | Toast внизу по центру, `--nav`, 4 с |
| Опасные действия | Сторно, отключение, удаление строки — диалог подтверждения с причиной; primary в диалоге danger |
| Права | Кнопки без права скрываются, а не выключаются; раздел без права не показывается в сайдбаре; прямой URL без права → экран «Нет доступа» с орнаментом |
| Период закрыт | Баннер `--warning` «Период закрыт до 31.08.2026» в документе; поля только для чтения |

## 8. Адаптив и плотность

| Ширина | Поведение |
|---|---|
| ≥1440 | Сайдбар 264, master-detail, правые панели 440 |
| 1280–1439 | Сайдбар 264, правые панели выдвижные поверх |
| 1024–1279 | Сайдбар свёрнут до 72 (иконки), формы master-detail — выдвижная панель |
| <1024 | Офис поддерживается в режиме просмотра: сайдбар — выезжающее меню, таблицы превращаются в карточки. Редакторы документов показывают «Откройте на компьютере» для строк больше 20 |

Плотность (`[data-density=compact]`): строки таблиц 40 px вместо 48, поля 36 px вместо 44. Переключатель есть в bahandi, но почти ничего не меняет — в Sandyq он реально подключается к `--control-h` и `--space-*`.
